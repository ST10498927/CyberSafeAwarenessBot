## Project Description

Cybersecurity Awareness Chatbot is a C# console application designed to help users learn basic cybersecurity awareness.

The chatbot provides simple information about password safety, phishing and safe browsing. It also uses a personalised greeting, input validation and a voice greeting when the application starts.

## Features

- Voice greeting
- Cybersecurity ASCII art header
- Personalised user greeting
- Password safety responses
- Phishing responses
- Safe browsing responses
- General cybersecurity questions
- Input validation
- Unsupported question handling
- Exit command
- Coloured console interface
- Structured classes and methods

## Technologies Used

- C#
- .NET 8
- Console Application
- GitHub
- GitHub Actions
